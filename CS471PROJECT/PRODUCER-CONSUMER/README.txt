# CS471 Course Project 

## Process Synchronization

This program simulates producers and consumers using threads,mutexes, and semaphores. It runs with different numbers of producers and consumers.

Output consists of:
- generate sales records via producers 
- process records via consumers 
- synchronized shared buffer 


### Executing the program

* To compile:
g++ main.cpp -o pc -pthread

* To run:
./pc
