# CS471 Course Project 

## CPU Scheduling

This program simulates a CPU scheduler; it reads 500 processes from an input. Each line contains: arrival_time burst_time

The output consists of:
- Total time elapsed
- Throughput
- CPU utilization
- Average waiting time
- Average turnaround time
- Average response time


### Executing the program

* To compile:
g++ main.cpp -o sched

* To run:
./sched input.txt FIFO
./sched input.txt SJF
